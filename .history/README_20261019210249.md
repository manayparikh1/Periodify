# Periodify

Basically what I made is a small easy-to-read periodic table that contains all the elements ranging from alkali metals all the way to transitional ones. I also have like a 7 question VERY simple quiz in the bottom of the page.

Below is the table I created and when you hover or click on it you can view small details about the element.

![images/mytable.png](mytable.png)

## Features

- Atomic Symbol
- Atomic Number
- Element Name
- The Legend (Differentiates the elements in their groups)
- Quiz Function with 7 Questions
